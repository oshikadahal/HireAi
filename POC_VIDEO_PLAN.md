# Proof of Concept Video Plan

## Scene 1: Introduction
- Show the app overview and explain the recruitment problem.

## Scene 2: Security Features
- Demonstrate secure registration, login, password policy, MFA setup, and secure cookies.

## Scene 3: Vulnerability 1
- Show a weak password registration attempt being rejected.
- Explain the root cause and fix.

## Scene 4: Vulnerability 2
- Demonstrate a CSRF-style forged state-changing request being blocked.
- Explain the root cause and mitigation.

## Scene 5: Retesting
- Show the fixed behaviour after the remediation.

## Production Notes
- Face visible throughout
- Clear audio
- Closed captions enabled
- Record in a quiet environment
