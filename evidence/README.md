# Evidence Folder

This directory stores the supporting evidence for the coursework penetration testing work. It includes payload examples, testing notes, and placeholder locations for screenshots that can be added during the final presentation or submission package.

Suggested structure:
- screenshots/weak-password-test.png
- screenshots/csrf-test.png
- payloads/weak-password-payload.txt
- payloads/csrf-payload.txt
- notes/testing-log.txt

The files in this folder should be kept alongside the report so that the security findings can be reviewed independently of the source code.
